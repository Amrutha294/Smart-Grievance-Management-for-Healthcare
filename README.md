# Smart Grievance Management for Healthcare

## Project Overview
The Smart Grievance Management for Healthcare system is designed to provide a secure and efficient platform for managing hospital grievances and feedback. It enables users to submit complaints, track their status, and receive resolution updates in a transparent manner.

## Features
- User authentication and role-based access
- Grievance submission and tracking
- Admin dashboard for grievance management
- Status updates and notifications
- Secure and scalable architecture

## Tech Stack
- Backend: Java, Spring Boot
- Frontend: React
- Database: MySQL
- Tools: GitHub, VS Code

## Project Structure
- resolveit-backend
- resolveit-ui-frontend
- document

## How to Run
1. Clone the repository
2. Configure database settings
3. Run backend using Spring Boot
4. Start frontend using React
